# v0.2.2 更新说明

## 版本信息

| 项目 | 值 |
|---|---|
| 版本 | v0.2.2 |
| 基础镜像 | python:3.11-slim |
| TTS 引擎 | piper-tts 1.8.0（`[zh]` extra） |
| 镜像标签 | `v0.2.2`、`latest` |

## 主要变更

### 1. 修复 pinyin 中文音色报错

v0.2.1 使用 `piper-tts 1.2.0`，其音素类型枚举中没有 `pinyin`，加载
`zh_CN-chaowen-medium`、`zh_CN-xiao_ya-medium` 等模型时直接失败：

```
'pinyin' is not a valid PhonemeType
```

v0.2.2 升级到 `piper-tts 1.8.0`，并安装 `[zh]` extra（g2pW + transformers）：

- 构建时下载并解压 g2pW 模型（`g2pw.onnx` + 字表）到 `/opt/piper-data/g2pW`
- 预置 `bert-base-chinese` tokenizer 到 `/opt/piper-data/bert-base-chinese`
- 改写 g2pW 的 `config.py`，让 `model_source` 指向本地 tokenizer
- 运行镜像设置 `HF_HUB_OFFLINE=1` / `TRANSFORMERS_OFFLINE=1`，合成时不再联网
- 合成接口适配 1.8.0 的 `SynthesisConfig`，句间静音仍保持 0.2 秒

默认内置音色新增：

- `zh_CN-chaowen-medium`
- `zh_CN-xiao_ya-medium`

### 2. 前端 Header 紧凑化

Header 从「居中三行（图标 / 标题 / 副标题 / 徽标）」改为单行卡片式品牌栏：

- 图标 56px → 40px
- 标题与副标题横向排列，副标题 14px → 12.5px
- 离线徽标移到右侧，窄屏自动隐藏
- 低高度屏幕（≤720px）进一步压缩为 34px 图标 + 单行标题

整体高度由约 180px 降至约 60px，为表单和历史列表释放更多空间。

### 3. 历史语音支持删除

- 新增 `DELETE /api/audio/<filename>`：同时删除 `.wav` 与 `.json` 元数据
- 历史列表每项增加红色删除按钮，删除前弹出确认
- 删除当前正在预览的音频时，播放器自动重置
- 后端校验文件名，拒绝路径穿越与非 `.wav` 文件

## 升级方式

```bash
docker pull ccr.ccs.tencentyun.com/mikewong/flask-tts:v0.2.2
docker compose down
docker compose up -d
```

数据卷 `flask-tts-audio` / `flask-tts-voices` 保持不变。
