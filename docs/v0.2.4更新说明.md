# v0.2.4 更新说明

## 版本信息

| 项目 | 值 |
|---|---|
| 版本 | v0.2.4 |
| 基础镜像 | python:3.11-slim |
| TTS 引擎 | piper-tts 1.8.0（`[zh]` extra） |
| 镜像标签 | `v0.2.4`、`latest` |

## 问题现象

v0.2.3 已经使用 LRU 模型缓存并设置 `PIPER_MODEL_CACHE_SIZE=1`，但：

- amd64 机器生成几段话后 RSS 约 650–730 MB
- arm64（armbian）只使用一个拼音音色，RSS 仍达到 1.25 GB
- 容器刚启动时仅约 20 MB

实测单次长文本即可复现：

| 阶段 | RSS |
|---|---|
| 容器启动 | 37 MB |
| 加载 xiao_ya + g2pW | ~374 MB |
| 合成一段约 500 字长文本 | **~1.38 GB** |

## 根因

不是模型缓存，也不是每次请求泄漏，而是 **ONNX Runtime 默认内存池**：

- `SessionOptions.enable_cpu_mem_arena = True`（默认）
- `SessionOptions.enable_mem_pattern = True`（默认）

ORT 会把推理过程中的临时内存保留在 arena 中，长文本/长音素序列会显著抬高
arena 的高水位；之后的短请求不会让它降下来，因此 RSS 一直维持在高位。

除了 Piper 主模型，g2pW 的 ONNX 会话也有同样问题。

## 修复内容

### 1. 主模型关闭 ORT 内存池

`PiperEngine._create_piper_voice()` 不再直接调用 `PiperVoice.load()`，而是自行创建：

```python
options = onnxruntime.SessionOptions()
options.enable_cpu_mem_arena = False
options.enable_mem_pattern = False

session = onnxruntime.InferenceSession(
    model_path,
    sess_options=options,
    providers=["CPUExecutionProvider"],
)
voice = PiperVoice(session=session, config=config, ...)
```

### 2. g2pW 关闭 ORT 内存池

g2pW 内部自行创建 `SessionOptions`，初始化共享音素化器时临时替换默认值，
让 `g2pw.onnx` 会话同样关闭 arena / memory pattern。

### 3. 新增环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PIPER_ORT_MEM_ARENA` | `0` | 是否启用 ORT CPU 内存池；`0` 更省内存 |
| `PIPER_ORT_MEM_PATTERN` | `0` | 是否启用 ORT memory pattern；`0` 更省内存 |

默认即为省内存配置，无需在 compose 中额外设置。

## 实测效果

| 场景 | v0.2.3 | v0.2.4 |
|---|---|---|
| 单次长文本（约 500 字） | ~1.38 GB | **~377 MB** |
| 4 个音色交替（含长文本） | ~1.2 GB+ | **~410–456 MB** |
| 缓存=1 + 反复长文本 | 持续高位 | 稳定 ~450 MB |

## 升级方式

将 compose 镜像改为 `v0.2.4`：

```yaml
services:
  flask-tts:
    image: ccr.ccs.tencentyun.com/mikewong/flask-tts:v0.2.4
    container_name: flask-tts
    ports:
      - "5001:5001"
    environment:
      # 常驻内存的模型数量（LRU）；1 最省内存
      PIPER_MODEL_CACHE_SIZE: "1"
    volumes:
      - flask-tts-audio:/app/static/audio
      - flask-tts-voices:/app/voices
    restart: unless-stopped

volumes:
  flask-tts-audio:
    name: flask-tts-audio
  flask-tts-voices:
    name: flask-tts-voices
```

```bash
docker compose down
docker compose pull
docker compose up -d
```

## 兼容性

- API 与 v0.2.3 完全兼容
- 数据卷、音色、配置不变
- 关闭内存池可能使单次长文本合成略慢，但常驻内存显著下降
