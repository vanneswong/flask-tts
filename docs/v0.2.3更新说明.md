# v0.2.3 更新说明

> 注意：长文本合成仍会因 ONNX Runtime 内存池导致 RSS 保持高位，
> 该问题已在 [v0.2.4](v0.2.4更新说明.md) 中修复。

## 版本信息

| 项目 | 值 |
|---|---|
| 版本 | v0.2.3 |
| 基础镜像 | python:3.11-slim |
| TTS 引擎 | piper-tts 1.8.0（`[zh]` extra） |
| 镜像标签 | `v0.2.3`、`latest` |

## 问题现象

v0.2.2 镜像长时间运行后，容器内存从约 200 MB 持续增长到 1.8 GB，重启后恢复。

## 原因分析

### 1. 模型缓存无上限

`PiperEngine._models` 会永久缓存所有使用过的音色模型。每个 Piper ONNX 模型
常驻约 85–150 MB；内置 4 个音色全部使用后，仅模型就会占用约 400–500 MB。

### 2. 每个拼音音色重复加载 g2pW

`phoneme_type=pinyin` 的音色（chaowen、xiao_ya）在首次合成时会初始化
`ChinesePhonemizer`，其中包含：

- g2pW ONNX 模型（159 MB）
- BERT tokenizer
- onnxruntime 会话与推理内存

Piper 默认把这个音素化器缓存在每个 `PiperVoice` 实例上，因此**每个拼音音色都会
各自加载一份 g2pW**。实测每份约 200 MB：

| 阶段 | RSS |
|---|---|
| Python 基线 | 8 MB |
| 加载 chaowen 模型 | 138 MB |
| chaowen 首次 g2pW 音素化 | 377 MB |
| 加载 xiao_ya 模型 | 461 MB |
| xiao_ya 首次 g2pW 音素化 | 646 MB |

### 3. 内存未及时归还系统

模型被移除后，Python 对象虽然释放，但 glibc / onnxruntime 的 arena 可能继续保留
内存，RSS 不会立即下降。Flask 多线程请求还会进一步放大 glibc arena 数量。

> 说明：同一音色、不同文本长度反复合成时，内存会稳定在一个上限附近，并非每次
> 请求都无上限泄漏；主要增长来自「多音色模型常驻 + 每个拼音音色重复加载 g2pW」。

## 修复内容

### 1. 拼音音色共享 g2pW

`PiperEngine` 只初始化一份 `ChinesePhonemizer`，所有 `phoneme_type=pinyin`
的 `PiperVoice` 共用该实例。第二个拼音音色不再额外加载 159 MB 模型。

### 2. 模型缓存改为 LRU

- 使用 `OrderedDict` 记录访问顺序
- 默认最多保留最近使用的 **2** 个模型
- 新增环境变量 `PIPER_MODEL_CACHE_SIZE`：
  - `2`（默认）：兼顾多音色切换与内存
  - `1`：最省内存，切换音色时重新加载模型
  - `<=0`：不限制（保持旧行为，不推荐）

### 3. 主动归还内存

淘汰模型时执行：

```python
gc.collect()
ctypes.CDLL("libc.so.6").malloc_trim(0)
```

### 4. 限制 glibc arena 数量

镜像新增环境变量：

```dockerfile
MALLOC_ARENA_MAX=2
```

减少多线程请求下 malloc arena 膨胀。

## 实测效果

| 场景 | v0.2.2 | v0.2.3 默认（缓存 2） | v0.2.3 缓存 1 |
|---|---|---|---|
| 仅 1 个拼音音色 | ~450 MB | ~414 MB | ~416 MB |
| 4 个音色交替使用 | ~1.23 GB | ~550 MB | ~420 MB |
| 24 次混合请求后 | 持续增长 | 稳定 ~550 MB | 稳定 ~420 MB |

> 测试文本为中英文混合短句，模型为镜像内置的 4 个音色。

## 升级方式

将 compose 中的镜像改为 `v0.2.3`，并加入 `PIPER_MODEL_CACHE_SIZE`：

```yaml
services:
  flask-tts:
    image: ccr.ccs.tencentyun.com/mikewong/flask-tts:v0.2.3
    container_name: flask-tts
    ports:
      - "5001:5001"
    environment:
      # 常驻内存的模型数量（LRU）；1 最省内存
      PIPER_MODEL_CACHE_SIZE: "1"
    volumes:
      - flask-tts-audio:/app/static/audio
      - flask-tts-voices:/app/voices
    restart: unless-stopped

volumes:
  flask-tts-audio:
    name: flask-tts-audio
  flask-tts-voices:
    name: flask-tts-voices
```

```bash
docker pull ccr.ccs.tencentyun.com/mikewong/flask-tts:v0.2.3
docker compose down
docker compose up -d
```
